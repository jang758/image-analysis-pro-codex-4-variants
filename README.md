# Image Analysis Pro — Four App Variants

각 HTML 파일은 별도 설치 없이 브라우저에서 실행할 수 있습니다. / Each HTML file runs directly in a browser without installation.

각 HTML 앱을 처음 실행할 때 `공통 results 폴더 연결` 버튼으로 이 저장소의 [`results`](results/) 폴더를 선택하세요. 네 앱은 완료된 TXT와 원본 참조 이미지를 이 한 폴더에 앱별 파일명으로 자동 누적합니다. / When first using each HTML app, connect this repository's [`results`](results/) folder. All four apps automatically accumulate TXT results and unchanged reference images there, distinguished by app-specific filenames.
