# Image Analysis Pro Pose & Face v3.0.2 기존 하네스 사용설명서

## 주요 기능

- 포즈를 최우선, 얼굴과 표정을 차순위로 분석합니다.
- 두 단계로 처리합니다.
  1. 원본 이미지를 전체 장면 → 신체·얼굴·접촉 세부 → 전체 재조립 순서로 분석
  2. 첫 단계 분석만 사용하여 이미지 생성 프롬프트 작성
- 분석과 생성 프롬프트를 영어·한국어·전체 보기로 제공합니다.
- 선택한 Gemini 모델이 두 단계를 모두 처리하며 자동으로 다른 모델로 바꾸지 않습니다.
- Agentic Vision을 켜면 첫 번째 이미지 분석 단계에서 선택 모델의 코드 기반 확대·크롭 조사를 허용합니다.
- 모델, Agentic Vision 실행, 처리 시간, 토큰, 예상 비용, 자동·수동 재시도와 오류 이유를 실행 리포트에 기록합니다.
- 큰 이미지는 분석용으로 자동 축소합니다. 완료 결과는 공통 `results` 폴더에 한 TXT와 원본 이미지로 자동 저장합니다.

## 메뉴 설명

### 설정

| 메뉴 | 기능 |
|---|---|
| Gemini API Key | Gemini API 키 입력. 키는 저장되지 않으며 입력칸의 `Ctrl+V`는 키 붙여넣기로 동작합니다. |
| Model | 사용할 Gemini 모델 선택. 기본값은 `gemini-pro-latest`입니다. |
| Custom Model | 목록에 없는 모델 ID를 직접 입력합니다. 값이 있으면 Model 선택보다 우선하므로 평소에는 비워 둡니다. |
| Temperature | 출력 변동성을 설정합니다. Gemini 3 최신 계열에는 전송하지 않고 모델 기본값을 사용합니다. |
| Max tokens — Analysis | 긴 분석의 최대 출력 토큰 수입니다. |
| Max tokens — Prompt | 생성 프롬프트의 최대 출력 토큰 수입니다. |
| Thinking | 모델의 사고 수준을 선택합니다. |
| Thinking budget — Gemini 2.5 | Gemini 2.5의 사고 토큰 예산입니다. `-1`은 동적 할당입니다. |
| Camera Description Style | 생성 프롬프트의 카메라 표현을 숫자, 영문 철자 또는 생략으로 설정합니다. EXIF를 읽는 기능은 아닙니다. |
| Agentic Vision | 첫 단계에서 선택 모델의 코드 기반 확대·크롭 조사를 허용합니다. Thinking Off에서는 사용할 수 없습니다. |
| 설정 저장 | API 키를 제외한 설정을 브라우저에 저장합니다. |
| 설정 초기화 | 저장된 설정과 현재 API 키 입력을 초기화합니다. |
| 모델 목록 새로고침 | API 키로 현재 계정에서 사용할 수 있는 분석 모델을 불러옵니다. |
| 선택 모델 테스트 | 현재 모델, API 키와 요청 형식이 작동하는지 짧게 확인합니다. |
| 공통 results 폴더 연결 | 프로젝트 루트의 `results` 폴더를 자동 저장 위치로 연결합니다. |
| Safety OFF | 조정 가능한 네 가지 안전 필터를 OFF로 요청한다는 상태 표시입니다. |

### 이미지 입력과 히스토리

- 입력 영역 클릭, 드래그 앤 드롭, 페이지에서 `Ctrl+V`, 또는 `파일 선택`으로 이미지를 추가합니다.
- `NET` 표시는 브라우저의 온라인 상태를 보여 줍니다.
- `저장된 히스토리`에는 분석 결과와 리포트 텍스트가 저장됩니다. `보기`로 열거나 `히스토리 지우기`로 삭제합니다.

### 작업 카드

| 메뉴 | 기능 |
|---|---|
| 분석 | 두 단계 분석을 시작합니다. |
| 취소 | 현재 실행을 취소합니다. |
| 현재 선택 모델로 실패 단계 재시도 | 자동 재시도까지 실패한 단계부터 현재 선택 모델로 다시 실행합니다. 완료된 앞 단계는 유지합니다. |
| 현재 상태로 종결 | 더 이상 재시도하지 않고 현재 결과와 실패 이유를 확정해 히스토리와 `results` 폴더에 저장합니다. |
| 다시 저장 | 현재 TXT와 원본 이미지를 덮어쓰지 않는 새 공통 파일명으로 다시 저장합니다. |
| 삭제 | 화면에서 작업 카드를 제거합니다. |

### 결과 영역

- `긴 분석`: 장면, 포즈, 얼굴, 접촉, 가림, 카메라·조명과 재조립 분석
- `생성 프롬프트`: 긴 분석을 근거로 만든 이미지 생성 프롬프트
- `실행 리포트`: 최초·최종 모델, 단계별 요청·응답 모델, Agentic Vision, 시간, 토큰, 예상 비용과 오류
- 각 영역에서 `EN`, `KR`, `전체` 탭을 선택하고 `복사`로 현재 탭을 복사합니다.
- `처리 로그 / 오류`에서 단계별 HTTP 상태, 시간, 재시도와 실패 이유를 확인합니다.

## 사용 방법

1. `기존하네스.html`을 브라우저에서 엽니다.
2. 이 HTML 앱을 처음 사용할 때 `공통 results 폴더 연결`을 누르고 이 저장소의 `results` 폴더를 선택합니다.
3. Gemini API Key와 Model을 설정하고 필요하면 `선택 모델 테스트`를 누릅니다.
4. 토큰, Thinking, Camera Description Style과 Agentic Vision을 설정한 뒤 이미지를 추가하고 `분석`을 누릅니다.
5. 완료되면 한 TXT에 긴 분석·생성 프롬프트·실행 리포트의 EN/KR 원문이 함께 저장되고 원본 이미지는 같은 기본 파일명의 `_ref` 파일로 저장됩니다.
6. 저장 파일명은 `날짜_시간_밀리초_v302_PoseFace_기존하네스_원본명` 형식이며 기존 파일을 덮어쓰지 않습니다.
7. 다시 저장하려면 `다시 저장`을 누릅니다.
8. 자동 재시도 후에도 실패하면 필요에 따라 모델을 바꾼 뒤 `현재 선택 모델로 실패 단계 재시도`를 누릅니다.
9. 재시도하지 않을 경우 `현재 상태로 종결`을 눌러 현재 결과와 오류를 저장합니다. 히스토리를 여는 동작은 파일을 새로 저장하지 않습니다.
